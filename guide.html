How to Play

Objective

Capture tiles on the board and score more points than your opponent. The game ends when all tiles are owned.

Starting Setup

  • Player 1 starts with the top-left and bottom-right corners.
  • Player 2 starts with the top-right and bottom-left corners.
  • Corner tiles begin with a base value of 5.
  • All other tiles start at 0.

Valid Moves

You may place a tile only if:

  • The tile is empty
  • It is adjacent (including diagonals) to any owned tile

Valid moves for the human player are visually highlighted.

Capturing Tiles

When you place a tile:

  • The tile becomes yours
  • Its base value increases by +1
  • All adjacent tiles (8 directions):
    • Switch to your ownership
    • Each gain +1 base value

Scoring

Your score is the sum of base values of all tiles you own.

Scores update automatically after every move.

Game End

  • The game ends when no empty tiles remain.
  • The player with the higher score wins.
  • If scores are equal, the game is a tie.
